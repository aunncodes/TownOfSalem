# Town of Salem

> A recreation of the popular [Town of Salem](https://www.townofsalem.io/) Game, using Python and Node

This project uses a FastAPI backend, connected to an engine built entirely from scratch!
The frontend is coded in React.

## Setup
1. Clone the project
```bash
git clone github.com/aunncodes/TownOfSalem.git
```

2. Install frontend dependencies
```bash
cd frontend
npm install
```

3. Install backend dependencies
```bash
cd backend
pip install -r requirements.txt
```

4. Run the project
```bash
npm run dev
fastapi dev main.py
```
